Date Range Picker — clickable prototype

Theme: Base · Lumo · Aura

One field with a start and an end input that share a single calendar overlay. The focused input decides which date a pick sets:

  • Picking the start clears the old end, keeps the overlay open and moves focus to the end input.
  • While picking the end, hovering or focusing a date previews the range.
  • Picking the end commits the range and closes the overlay.
  • While picking the end, a date before the start becomes the new start instead.
  • Clicking the end input directly lets you change only the end.
  • Escape or Cancel restores the range from when the overlay was opened.
