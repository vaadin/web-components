Date Range Picker — clickable prototype

Theme: Base · Lumo · Aura

One field with a start and an end input that share a single calendar overlay. The focused input decides which date a pick sets:

  • Picking the start keeps the end when the range stays valid, and closes the overlay. If there is no end, or the new start is after it, the end is cleared and focus moves to the end input.
  • Hovering or focusing a date previews the range that picking it would select.
  • In the calendar, the date being edited is outlined, while the other end of the range stays filled.
  • The calendar button always opens the overlay for picking the start.
  • With a mouse, drag across dates to select a range, or drag the start or end of a range to move it.
  • Picking the end commits the range and closes the overlay.
  • While picking the end, a date before the start becomes the new start instead.
  • Escape or Cancel restores the range from when the overlay was opened.
  • With the overlay closed, Escape clears both dates when the clear button is visible.
