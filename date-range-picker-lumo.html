Date Range Picker — clickable prototype

Theme: Base · Lumo · Aura · Frozen earlier versions: v1, v2

One field with a start and an end input that share a single calendar overlay:

  • Clicking anywhere in the field picks the whole range: the start, then the end.
  • Moving to the end input with the keyboard, then opening the calendar, edits only the end.
  • While picking a range for the first time, hovering or focusing a date previews the range that picking it would select. When editing an existing range, the range stays on display and the hovered date is only hinted at with a dashed outline.
  • The input whose date a pick sets is highlighted. In the calendar, the date being edited has a lighter fill than the other end of the range.
  • With a mouse, drag across dates to select the whole range at once, which closes the overlay like picking the end does.
  • Drag a picked start to move it, then pick the end. Drag the start or end of a range to move it: the overlay stays open for further adjustments, close it with Escape or by clicking outside.
  • Escape and clicking outside close the overlay and keep what was picked, such as a start without an end.
  • Cancel restores the range from when the overlay was opened.
  • The clear button, or Escape with the overlay closed, clears both dates.
