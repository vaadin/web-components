Date Range Picker — clickable prototype

Theme: Base · Lumo · Aura · Frozen v1

One field with a start and an end input that share a single calendar overlay:

  • Clicking anywhere in the field picks the whole range: the start, then the end.
  • Moving to the end input with the keyboard, then opening the calendar, edits only the end.
  • Hovering or focusing a date previews the range that picking it would select. A date that starts a new range, such as one before the start while picking the end, previews as the only date of the range.
  • The input whose date a pick sets is highlighted. In the calendar, the date being edited has a lighter fill than the other end of the range.
  • With a mouse, drag across dates to select a range, or drag the start or end of a range to move it.
  • Escape or Cancel restores the range from when the overlay was opened.
  • The clear button, or Escape with the overlay closed, clears both dates.
