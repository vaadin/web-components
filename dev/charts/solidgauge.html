Point colorIndex in styled mode (highcharts/highcharts#23279)

Composed gauge from the upstream report: a solidgauge arc series plus a gauge pointer series, with plotLines and a plotBand on the same yAxis. No stops, minColor or maxColor are set anywhere.

  • Arc 1 — point colorIndex: 0, same as the series. This is the case in the upstream report; the CSS workarounds suggested there cover it.
  • Arc 2 — point colorIndex: 3, different from the series colorIndex: 0. No CSS workaround can cover this one, because the point path has no color class left to select. The arc must be a different color than in Arc 1.
  • Arc 3 — same as Arc 2 but with yAxis.stops. Here the color axis paints the point, so the arc follows the gradient and colorIndex is ignored by design.
